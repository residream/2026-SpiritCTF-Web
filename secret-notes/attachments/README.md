# 秘密便签

小 r 有很多不想让别人看到的小心思——半夜冒出来的灵感、还没想好的计划、一些只写给自己的话，于是他用业余时间搭了个「秘密便签」，把它们一条条收了起来。

他还挺讲究：每条便签都能设优先级，他又特意写了个「排序偏好」，想按什么顺序排列便签都行。最要紧的那一条，他干脆加了把锁，口令只有自己知道。

据说管理员那条锁着的便签里，藏着他最在意的东西。你能把它读出来吗？

---

## 本地运行

```bash
cd secret-notes && docker compose up --build
```

打开 http://localhost:3000，用 `admin` / `local-dev-password` 登录，即可在本地审计、复现。

（线上实例的 admin 密码是随机的，需要自己收集。）
